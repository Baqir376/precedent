# Precedent

**Catch work that contradicts your team's past decisions — before it ships.**

Precedent is an Atlassian Forge app for Jira, built for Codegeist 2026. It keeps a log of your team's decisions
(rationale, rejected alternatives, owner, revisit conditions) and checks every new or edited Jira work item against it.
It includes a Rovo agent, an MCP server and a Teamwork Graph import from Confluence, and it runs on Atlassian.
